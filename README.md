# Sauel Almonte Portfolio

This is my personal web portfolio.  
It serves as a showcase of my projects, skills, and background as a developer. The site features responsive design, scroll-based animations, and support for both light and dark modes.

This project is not intended for reuse or local development — it's solely built to represent my work and experience.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
